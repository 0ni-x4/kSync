## Performance Tips

### Optimization Strategies

1. **Use Factory Functions**
   ```ts
   // Optimized for chat
   const chat = createChat('room-id');
   
   // Optimized for gaming
   const game = createGame('game-id');
   ```

2. **Configure Batching**
   ```ts
   const ksync = createKSync({
     performance: {
       batchSize: 100,    // Higher for throughput
       batchDelay: 5      // Lower for real-time
     }
   });
   ```

3. **Enable Caching**
   ```ts
   const ksync = createKSync({
     state: {
       enableCaching: true,
       autoMaterialize: false
     }
   });
   ```

### Memory Management

- **Event Trimming**: Automatically removes old events
- **State Caching**: Caches materialized state for performance
- **Batch Processing**: Groups operations for efficiency
- **Lazy Loading**: Only processes what's needed

## Production Recommendations

### Scaling Guidelines

- **< 100 users**: Default settings work perfectly
- **100-500 users**: Increase batch size to 200
- **500-1000 users**: Enable compression, optimize batching
- **1000+ users**: Consider horizontal scaling

### Configuration for Scale

```ts
// Production configuration for 1000+ users
const ksync = createKSync({
  performance: {
    batchSize: 200,
    batchDelay: 5,
    materializationCaching: true,
    compressionThreshold: 512
  },
  offline: {
    queueSize: 10000,
    persistence: true
  },
  debug: {
    events: false,  // Disable in production
    performance: true
  }
});
```

## Continuous Monitoring

kSync includes built-in performance monitoring:

```ts
// Get real-time performance metrics
const status = ksync.getStatus();
console.log('Events/sec:', status.performance.eventsPerSecond);
console.log('Memory usage:', status.performance.memoryUsage);
console.log('Sync latency:', status.sync.averageLatency);
```
