## What is kSync?

kSync is a **schema-driven, Bun-native, real-time synchronization engine** designed for modern web and AI applications that need full control over event storage, tab synchronization, and backend integration — without the bloat.

## Quick Example

Here's how simple it is to get started with kSync:

```typescript
import { z } from 'zod';
import { ksync } from '@klastra/ksync';

// Define your event schema
ksync.defineSchema("message", z.object({
  id: z.string(),
  content: z.string(),
  author: z.string(),
  createdAt: z.number(),
}));

// Listen to events
ksync.on("message", (event) => {
  console.log(`New message: ${event.data.content}`);
});

// Send events (stored locally first, then synced)
await ksync.send("message", {
  id: "msg-1",
  content: "Hello world!",
  author: "Alice",
  createdAt: Date.now(),
});
```
