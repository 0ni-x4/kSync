## What is kSync?

kSync is a **next-generation, schema-driven sync engine** that brings database-like functionality to real-time applications. Designed for modern web and AI apps that need full control over data synchronization, collaboration, and offline functionality — without the complexity.

## Key Features

<AccordionGroup>
  <Accordion title="🗄️ Database-Like Queries" icon="database">
    Query your real-time data with SQL-like syntax using findMany(), where(), orderBy(), and more. Built on Drizzle ORM integration.
  </Accordion>

  <Accordion title="🔀 CRDT Conflict Resolution" icon="arrows-rotate">

  </Accordion>

  <Accordion title="🏪 Multi-Store Architecture" icon="layer-group">
    Manage multiple isolated data stores with cross-store operations, derived stores, and shared synchronization for complex applications.
  </Accordion>

  <Accordion title="📡 Dual Sync Modes" icon="arrows-spin">
    Choose between real-time WebSocket sync or git-like pull/push model. Perfect for offline-first apps that need reliable synchronization.
  </Accordion>

## Why Choose kSync?

<Tabs>
  <Tab title="Simple">
    **A 15-year-old could understand and implement it**
    
    kSync's architecture is intentionally simple. Events go in, state comes out. No complex abstractions or hidden magic.
  </Tab>
  
  <Tab title="Fast">
    **Built on Bun with minimal overhead**
    
    Leverages Bun's native performance with efficient event batching, connection pooling, and optimized data structures.
  </Tab>
  
  <Tab title="Local-First">
    **Works offline, syncs when online**
    
    Your app continues working even when the network is down. Events are stored locally and synced when connectivity returns.
  </Tab>
  
  <Tab title="Type-Safe">
    **Full TypeScript support with runtime validation**
    
    Catch errors at compile time with TypeScript, and ensure data integrity at runtime with Zod schemas.
  </Tab>
  
  <Tab title="Minimal">
    **No bloat, just the essentials**
    
    Only includes what you need for real-time sync. No unnecessary dependencies or features you'll never use.
  </Tab>

## Quick Example

Here's how simple it is to get started with kSync:

```typescript
import { z } from 'zod';
import { ksync } from '@klastra/ksync';

// Define your event schema
ksync.defineSchema("message", z.object({
  id: z.string(),
  content: z.string(),
  author: z.string(),
  createdAt: z.number(),
}));

// Listen to events
ksync.on("message", (event) => {
  console.log(`New message: ${event.data.content}`);
});

// Send events (stored locally first, then synced)
await ksync.send("message", {
  id: "msg-1",
  content: "Hello world!",
  author: "Alice",
  createdAt: Date.now(),
});
```

kSync is perfect for:

- **📱 Real-time chat applications** with typing indicators, presence, and conflict-free message ordering
- **📝 Collaborative editing tools** with CRDT-powered conflict-free synchronization (Google Docs style)
- **🎮 Multiplayer games** with real-time player movement, state sync, and presence tracking
- **🤖 AI-powered applications** with streaming responses and optimistic updates
- **📊 Dashboard applications** with SQL-like queries and live data updates
- **📋 Todo/Project management apps** with multi-store organization and offline sync
- **🏪 E-commerce platforms** with real-time inventory, cart sync, and collaborative shopping
- **📱 Offline-first mobile apps** with git-like sync when connectivity returns
- **🏢 Enterprise tools** requiring complex data relationships and reliable synchronization
